# ハチドリ NEWS PICK

ハチドリ電力の公式X・ユーザーコミュニティ向けニュースチェックページです。

- サインイン不要
- 直近72時間のニュースを最大24件表示
- 再エネ・脱炭素に加え、自然、生物多様性、循環、エシカル、まちづくりも収集
- ニュースを見渡しやすいリスト表示
- おすすめ順／新着順
- 記事ごとにX・LINEオープンチャット用の投稿案を自動作成
- それぞれの投稿文をワンクリックでコピー
- GitHub Actionsで3時間ごとに自動更新
